Four-Dimension Scoring
Each surviving candidate scored independently on four dimensions (0-100 each)
STQ Skill Transfer Quotient Weight: 45%
Measures skill transferability from PRW to target occupation.
Uses Jaccard similarity + token overlap (takes max).
STQ = 0.35 × Task/DWA Overlap
    + 0.25 × Work Field/MPSMS
    + 0.20 × Tools/Software
    + 0.10 × Materials/Services
    + 0.10 × Credentials/Knowledge
Acquired SkillsO*NET TasksDOT Work FieldsO*NET Tools
TFQ Trait Feasibility Quotient Weight: 25%
Quantifies reserve margin across all 24 traits.
Higher TFQ = more room between capacity and demands.
TFQ = (Σ trait_margins) / (24 × 4) × 100

margin = worker_capacity - occ_demand
Range: 0-100 (0 = barely passing)

PVQ Composite & Ranking
Weighted composite score determines final occupation ranking
PVQ Public Vocational Quotient
The final composite score for each occupation. Combines all four dimensions with empirically-derived weights.
PVQ = 0.45×STQ + 0.25×TFQ + 0.15×VAQ + 0.15×LMQ

Range: 0-100  |  Excluded occupations: PVQ = 0
Occupations ranked by PVQ descending
